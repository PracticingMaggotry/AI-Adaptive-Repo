Supported for demo: TXT and text-based PDF extraction. DOC/DOCX are saved for tracking but may need manual conversion to TXT/PDF.

How this module works

  1. Student uploads a file and assigns a topic.
  2. Backend stores the file details in MySQL.
  3. System extracts readable handout text and generates starter quiz questions for that topic.
  4. Student can immediately take the generated quiz.

Defense line: This demonstrates the handout integration pipeline with PDF/TXT text extraction and content-based quiz generation. Scanned PDFs may require OCR in a future version.
